## Features

- Live rooms with shareable links — no account required
- Private votes until everyone is ready to reveal
- Multiple decks: Fibonacci, T-shirt sizes, working days, and more
- Topic field so every hand has a clear story or ticket
- Moderators to keep the table moving
- Works in the browser on desktop and mobile
- Next-hand reset for the whole team

## Try it

1. Open [pointing.space](https://pointing.space)
2. Create or join a room
3. Share the link with your team and start pointing
